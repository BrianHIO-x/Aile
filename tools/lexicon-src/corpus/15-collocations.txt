# 词间搭配训练语料：常用搭配补充第二批。本项目自行编写，每行一句，标点处断开统计。
# 覆盖常见口语搭配骨架：有点+形容词、再+动词、又+动词、该+动词、动词+了、得与地、动量搭配。

# 有点 + 形容词
这碗汤有点咸，兑点水。
下午有点困，泡杯咖啡。
这件衣服有点贵，等打折。
路上有点堵，晚点到。
刚睡醒有点懵，缓一缓。
新手机有点慢，重启试试。
食堂有点吵，换个位置。
今天有点累，早点休息。
肚子有点饿，加个餐。
他有点忙，回头再找他。
这道题有点难，一起看看。
天有点黑了，开个灯。

# 再 + 动词
再试一次，说不定就成了。
再说吧，今天先到这里。
再找找看，应该还有库存。
再改一版，明天交稿。
再点两个菜，人多。
再加一小时班就走。
再睡十分钟，闹钟响了。
再买一件，凑单免邮。
再检查一遍，别出错了。
再确认下时间，怕记错。
再商量一下，明早答复。
再讨论十分钟，就散会。
再等一会儿，路上堵。
再看看评论区，再下单。

# 又 + 动词或形容词
菜价又降了，多买点。
他又迟到了，扣了全勤。
我又忘了带伞。
快递又来了，下楼取。
油又涨了，加满一箱。
雨又下起来了，收衣服。
手机又没电了，借个充电宝。
股票又跌了，先不看了。
他又赢了，运气真好。
物价又涨了一点。

# 该 + 动词
水电费该缴了，别断。
十一点了，该睡了。
饭点到了，该吃饭了。
该走了，再晚赶不上车。
作业该交了，抓紧写。
资料该更新了，有空整理。
头发该剪了，周末去。
假该批下来了，问问人事。

# 动词 + 了 的常见收尾
合同已经签了，放心。
快递签收了，谢谢。
他到站了，去接吧。
饭点过了，随便吃点。
灯关了，晚安。
密码改了，记牢。
账单清了，无债一身轻。
花盆搬进来了，夜里冷。
网费续上了，能上网了。
名单公布了，看看有没有你。
结果出来了，一切正常。
行李收拾好了，明早出发。

# 得 与 地
跑得气喘吁吁，歇一会儿。
话说得太满，收不回来了。
活儿干得漂亮，加个鸡腿。
球踢得真好，专业的。
觉睡得足，精神好。
饭吃得快，赶紧上学。
路走得稳，别慌。
价格降得不少，入手了。
他悄悄地走了。
大家努力地干，年底分红。
她细心地记下了每个要求。
师傅熟练地换了轮胎。

# 动量与数量搭配

取个快递就回来。

再招两个人，忙不过来。
新招了个助理，分担点活。
一部新剧，口碑不错。
这部电影看了两遍。
换个新手机，旧的给爸妈。
哪个出口近，从那边走。
几号门集合，别走错。
费用平摊，一人一半。
房租平摊，压力小点。
江边夜景不错，拍照去。
城市夜景灯火通明。
手机重置以后要重新登录。
密码重置了，用新的。
明天有雨，改天再爬山。
今天有雨，记得带伞。
是否有雨，看预报。

本地菜很好吃，划算。
那地方很好玩，值得去。
