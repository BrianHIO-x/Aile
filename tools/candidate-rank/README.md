# 候选排序离线回归

这个目录用真实词库和真实引擎验证候选排序，不依赖鸿蒙设备。排序函数本身在
`entry/src/main/ets/ime/CandidateRanking.ets`，输入法界面消费的是它生成的快照。

```powershell
powershell -ExecutionPolicy Bypass -File tools\candidate-rank\run.ps1
powershell -ExecutionPolicy Bypass -File tools\candidate-rank\probe.ps1   # 打印候选池与读音元数据
```

`run.ps1` 只写本目录的 `build\test`，`probe.ps1` 只写 `build\probe`，都不碰
`tools/engine-bench/build` 与 `tools/frontend-regress/build`。

## 数据从哪里来

引擎在生成候选时附带 `CandidateMeta`（`EngineTypes.ets`）：

- `reading`：`full` 完整音节、`fuzzy` 模糊等价读音、`abbreviation` 简拼或半截音节、
  `corrected` 相邻按键纠错。
- `complete`：消耗了整串输入。
- `safeEnd`：停在原文可以安全断开的音节边界。
- `exactConsumed`：这个词按原文完整音节最多能读到的位置。

排序只用这些字段和候选原有的 `syllables` 音节数组，不按文字长度猜切分，也不改分数。
原文候选与旧版提供者没有 `meta` 时按完整读音、安全边界处理。

## 普通候选栏（快选）

1. 第一个永远是候选池第一个，即用户固定首位或引擎首选；空格选中的就是它。
2. 长输入（不少于 10 个字母或首选读音不少于 4 个音节）或简拼输入时，选最多 4 个代表项
   提到前列，代表项之间仍按引擎顺序排列：
   - 覆盖整串的完整读音真实词；
   - 停在全串可安全断开处的整句分段；
   - 紧贴起始读音的真实前缀词，必须停在首选读音的完整音节末尾且音节序列是首选读音的前缀：
     取最短与最长各一个，短词负责起始音节，长词负责覆盖；
   - 停在首选第一个自然音节末尾的可靠单字。
3. 代表项之后保持引擎原顺序，但以下候选挪到后段：
   - 除第一条可靠整句之外的合成整句；纠错整句与简拼整句一律靠后；
   - 切进音节内部的替代切分；
   - 不是简拼输入时的简拼补全；
   - 第 3 条以后的纠错，以及覆盖不到输入一半的低覆盖纠错。
4. 原文永远在最后。

短全拼（如 `shi`）不晋升任何代表项，同音字、同音词保持引擎给出的词频与上下文顺序。
纯声母简拼只晋升完整的简拼词，不把整句、前缀或单字抬到完整词前面。

## 展开的“全部”

候选池第一个仍然是固定首位或引擎首选，其后按用途分档：

1. 完整读音真实词 → 模糊读音真实词 → 安全分段 → 简拼真实词；
2. 当前输入第一个自然音节的常用字（停在首选音节末尾的在前，其他安全边界次之，
   切进音节内部的在后）；
3. 模糊读音的字、简拼的字、纠错词与纠错的字；
4. 其余合成整句、替代切分，原文最后。

同一档内保持引擎顺序（词频与上下文），不按字数或长度重排。

## 展开的“词语”

只保留真正的词（两个字符以上、来源不是合成整句或原文）。分档顺序为
完整读音 → 模糊读音 → 简拼 → 纠错，同一档内再按是否停在安全音节边界分先后。
合成的整句只出现在“全部”，词库词与用户词因此排在它前面。

## 展开的“单字”

只保留单字。先按读音可靠度分档（完整 → 模糊 → 简拼 → 纠错），同一读音内：

1. 停在首选路径第一个自然音节末尾的字；
2. 停在其他安全音节边界的字；
3. 切进音节内部的替代切分。

`tian'anmen` 的首选读法是 tian/an/men，单字先列停在 tian 之后（边界 4）的字，
`ti` 切分的字不会混进首排；`xi'an` 由撇号分开时，读完 xi 的候选消耗包含撇号，
边界比较时按去掉撇号的字母位置进行。

## 与界面的接线

- `CompositionController.refresh` 生成候选池后调用 `rankCandidates`，保存
  `bar/all/words/chars` 四个序号数组；`CandidateView.index` 始终是候选池里的原始
  序号，点击与长按仍按这个序号解析，显示位置由数组先后单独决定。
- `ImeController.syncComposition` 把四份顺序映射成 `CandidateView` 引用，
  `CandidateBar` 用普通栏顺序并按下标显示首选项，`FreeSelectPanel` 直接消费
  `全部/词语/单字` 三个数组，不再原地过滤。
- 筛选为空时 `allowedFilter` 回到“全部”。

## 单字补位

候选池被 150 条上限截断、单字视图一个不剩时，`CompositionController` 会按首选候选
已经读通的第一个音节补一页候选：只收单字、同文本去重、条数上限 16，候选正好读完这个
音节，紧跟其后的显式撇号一并消耗。主查询的拼音切分在补查之前已存进
`formattedCode`，补查覆盖引擎最近一次查询不会改变预编辑显示。
